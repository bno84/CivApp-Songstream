# Civitai Radio

A Civitai app that feels like a music player.
Media control button support, playlists, shuffle.

**Status:** scaffolded, in early development.

## Develop

```bash
pnpm install
pnpm run dev          # local preview, no host behind it
pnpm run build
pnpm exec civitai app validate
```
